- 課題

  ブログの記事を作成した日付を元に、画面左下に表示しているカレンダーに記事の存在を視覚化している。ただ、記事を更新した場合は、この状況をカレンダーに表示していない。このため、記事を作成した日付・記事を更新した日付を元にカレンダーに記事の状況を表示する様に仕様を更新する

- カレンダー表示の変更方針

  | 状態 | セルの見た目 |
  |---|---|
  | 作成日 | 緑の丸（6px） |
  | 更新日 | 青のひし形（5pxの正方形を45度回転。対角線は約7px） |
  | 作成日と更新日が同じ日 | 丸とひし形が左右に並ぶ（中心間は12px） |
  | 更新日だけの日の背景 | 少し濃くした（0.2。ホバー時は0.32） |

  - 丸とひし形にした理由：同じ丸で色違いにするよりも、輪郭が違うほうが小さいサイズでも見分けやすいからです。ひし形は丸より角で大きく見えるので、見た目の大きさが揃うように丸より1px小さく作っています。
  - 凡例も同じ形に変更：カレンダーの下の「作成日」「更新日」の凡例も、丸とひし形に合わせました。
  - 青の色は維持：更新日の青（
#2f6fb0）は、記事ページの更新日の青字と同じ色のままにしています。色を変えると、記事ページとの対応が崩れるためです。


-  変更内容
    - **`BaseLayout.astro`**：サイドバーへ渡す記事データに`dateRevised`を追加しました。未設定の記事は`undefined`のままです
    - **`Sidebar.vue`**：`revisedDates`（更新日の一覧）を追加し、各日付セルに`hasRevision`の判定を持たせました。作成日と更新日のどちらかがある日はクリックできます
    - **ドットの色分け**：色だけに頼らないよう、ドットも併用しています。選択中の日は背景が緑になるため、更新日のドットは明るい色に変えています。
