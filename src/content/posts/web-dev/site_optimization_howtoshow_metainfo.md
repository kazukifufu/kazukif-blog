---
title: "デザインの更新: 記事のメタ情報を1行にまとめ、更新日を青字で表示する"
date: "2026-10-09"
category: "web-dev"
---

- 背景

  記事のFront Matterに`dateRevised`（更新日）を追加してから、既存記事を修正するたびに更新日を入れるようになった。ところが、実際に更新日付きの記事を表示してみると、メタ情報が**2行に分かれて**しまい、リングノート風にした本文の罫線とも相まって、やや間延びした印象になっていた。そこで、メタ情報を1行にまとめ、更新日だけを青字にして目立たせる調整を行いました。


- 変更前と変更後

  | | 表示 |
  | --- | --- |
  | 変更前（2行） | `infra ／ 2026/9/24`<br>`更新日：2026/9/29`（グレー、小さめの文字） |
  | 変更後（1行） | `infra / 作成日: 2026/9/24 / 更新日: 2026/9/29`（更新日の部分だけ青字） |

  「公開日」と「更新日」が同じ行に並ぶことで、どちらが元の日付でどちらが後から直した日付なのかが一目で比較できる。また、ラベルを「作成日」「更新日」と明示し、区切りも全角の`／`から半角の`/`に統一した。


- 実装：1つの`<p>`にまとめ、更新日だけ`<span>`で囲む

  - **テンプレート側の変更:** Template

     以前は`post-meta`と`date-revised`という2つの`<p>`要素を並べていたが、`post-meta`の中に更新日を含める形に変更した。

     ```astro
     <p class="post-meta">
       {post.data.category} / 作成日: {post.data.date.toLocaleDateString('ja-JP')}
       {post.data.dateRevised && (
         <>
           {' / '}
           <span class="date-revised">
             更新日: {post.data.dateRevised.toLocaleDateString('ja-JP')}
           </span>
         </>
       )}
     </p>
     ```

    - ポイント
        - **`<>`...`</>`（フラグメント）**：条件付きで描画する内容が「区切りの` / `」と「更新日の`<span>`」の2つあるため、Astroのフラグメント記法でまとめている。余計なラッパー要素を増やさずに済む
        - **区切りの` / `を`<span>`の外に置いた**：区切り文字まで青くならないよう、`{' / '}`という文字列として`<span>`の外に出している。青字になるのは「更新日: 〇〇」の部分だけになる
        - **`dateRevised`がない記事**：`{post.data.dateRevised && (...)}`の条件が偽になるため、区切りも更新日も出力されず、`infra / 作成日: 2026/9/24`だけが表示される
    - 表示例

      更新日の有無で、次のように表示が分かれる。

        | Front Matter | 表示 |
        | --- | --- |
        | `dateRevised`あり | `infra / 作成日: 2026/9/24 / 更新日: 2026/9/29`（更新日が青字） |
        | `dateRevised`なし | `infra / 作成日: 2026/9/24` |


  - **スタイル側の変更:**

     ```css
     .date-revised {
       color: #2f6fb0;
     }
     ```

     2行表示のために付けていた`margin: -16px 0 24px 0;`（直前の行との間隔を詰める調整）や、公開日より小さく薄くするための`font-size`・グレーの`color`は不要になったので削除した。今は`post-meta`の文字サイズ・行間をそのまま引き継ぎ、色だけを青に変えている。

     青には`#2f6fb0`を選んだ。リングノートの紙色（`#faf7ee`）の上でも読みやすく、罫線の青灰色（`rgba(107, 143, 165, 0.22)`）ともなじむ青である。
