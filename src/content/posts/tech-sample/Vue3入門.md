# Vue 3 構文入門

Vue 3から導入された **Composition API**（`<script setup>`）は、コードを関心のまとまりごとに整理できるため、大規模開発だけでなく、小規模なコンポーネントの作成にも非常に強力です。
![Vueのロゴ](/images/Tech/vue-logo.png)

## 主な特徴
- `ref` や `computed` を使った直感的な状態管理
- ロジックの再利用性が向上
- TypeScriptとの親和性が抜群

今回はこのVue 3の動的インポート機能を使って、Markdownサイトを構築しています。
