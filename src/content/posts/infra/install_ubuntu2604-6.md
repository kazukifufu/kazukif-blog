### システム全体のソフトウェアを最新バージョンへ更新

```bash
# パッケージリストを最新にする
sudo apt update
sudo apt upgrade
```

- `sudo apt update` は、Ubuntu（およびその他のDebian系Linux）で**インストール可能なパッケージ（ソフトウェア）の最新情報をリポジトリから取得し、ローカルのリストを更新するコマンド**です
  - 通常は、ソフトウェアを新しくインストールする前や、システムを更新する前に `sudo apt update` を実行します
  - コマンドの分解と詳細
    - **`sudo`**
      管理者権限(root権限)でコマンドを実行します。システムのパッケージ情報を更新するには管理者権限が必要なため付与します
    - **`apt`**
      Ubuntu標準のパッケージ管理ツール(Advanced Package Tool)です
    - **`update`**
      パッケージの「リスト（情報）」を最新化する

  - ⚠️ 重要：実際の「アップデート（更新）」は行われません
      このコマンドを実行しただけでは、システムに導入されている**プログラムそのものが更新（アップグレード）されるわけではありません**。

- `sudo apt upgrade` は、`sudo apt update` で取得した最新のパッケージリストを元に、**実際にシステム内のソフトウェア（パッケージ）を最新バージョンに更新（アップグレード）するコマンド**です
  - コマンドの分解と詳細
    - **`sudo`**
      管理者権限(root権限)でコマンドを実行します。システムのパッケージの変更・更新を行うため管理者権限が必要なため付与します
    - **`apt`**
      Ubuntu標準のパッケージ管理ツール(Advanced Package Tool)です
    - **`upgrade`**
      インストール済みパッケージを新しいバージョンへ更新する

  - `-y` オプションを付けると、途中の確認「Y/n」で自動的に Yes と答えて進めます
  - `-y` オプションを付けない場合、処理の途中で確認が入る。ダウンロードされるデータ容量や更新されるパッケージ一覧が表示され、Do you want to continue? [Y/n] と尋ねられます。y を押して Enter で更新が始まります
